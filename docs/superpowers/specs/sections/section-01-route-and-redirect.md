# Section 01: Route Creation and Redirect

## Overview

This section creates a new top-level route at `/ontology` and converts the old route at `/admin/ontology/browser` into a redirect. This is the foundation for promoting the ontology browser from a deeply nested admin page to a primary navigation target.

## Background

The application uses TanStack Router v1 with file-based routing. Route files in `frontend/src/routes/` map directly to URL paths. The Vite plugin auto-generates `frontend/src/routeTree.gen.ts` whenever route files change. The existing ontology browser component (`OntologyBrowser`) is a self-contained component that handles its own layout (split-pane with tree + detail panels), so no wrapper layout is needed.

The auth model relies on a root-level `AuthProvider` -- there are no per-route auth guards. The new `/ontology` route follows this same pattern, consistent with other top-level routes like `/projects`.

## Tests

No unit tests are needed for this section. TanStack Router file-based routes are validated by the build system and type-checked via the generated route tree. The redirect behavior is verified via Playwright E2E tests in Section 04.

## Implementation

### Step 1: Create the new route file

**Create file:** `frontend/src/routes/ontology.index.tsx`

This is a leaf route (using `.index.tsx` convention) because there are no child routes -- tab switching within the browser is internal component state, not URL-driven.

The file should:
- Import `createFileRoute` from `@tanstack/react-router`
- Import `OntologyBrowser` from `@/features/ontology/components/OntologyBrowser`
- Define the route at `/ontology/` using `createFileRoute`
- Define a simple page component that renders `<OntologyBrowser />` directly (no additional layout wrapper needed)

Route definition shape:

```typescript
export const Route = createFileRoute('/ontology/')({
  component: OntologyPage,
})
```

The component function simply returns `<OntologyBrowser />`. Follow the same minimal pattern used by the existing browser route at `frontend/src/routes/admin/ontology/browser.tsx` (which is 10 lines total).

### Step 2: Convert the old route to a redirect

**Modify file:** `frontend/src/routes/admin/ontology/browser.tsx`

Replace the entire contents of this file with a redirect. Use TanStack Router's `redirect` function thrown from `beforeLoad` to perform a permanent client-side redirect before the route component ever mounts.

Redirect shape:

```typescript
import { createFileRoute, redirect } from '@tanstack/react-router'

export const Route = createFileRoute('/admin/ontology/browser')({
  beforeLoad: () => {
    throw redirect({ to: '/ontology' })
  },
})
```

This preserves the route entry so that bookmarks and shared URLs pointing to `/admin/ontology/browser` continue to work by seamlessly redirecting to `/ontology`.

**Important:** Remove the `OntologyBrowser` import and the `OntologyBrowserPage` component function -- they are no longer needed in this file. The redirect fires before any component renders.
